Lifecycle: ACTIVE → REST / REVIEW → RECOVERY → ACTIVE

REST means preservation, not neglect. REVIEW means a public metadata signal merits inspection. RECOVERY means the prior review condition is no longer observed, not that a repair was performed. Transitions are recorded as evidence; no cabinet is modified.

Homeostasis is not a popularity contest

Inactive, old, or rarely updated cabinets are not automatically unhealthy. An archived cabinet can be intentionally preserved. A REVIEW flag is a request for inspection, not a compromise finding. Three witnesses report: inventory, continuity, provenance. HEGEMON holds the boundary; no automatic deletion, code change, or blocking.
