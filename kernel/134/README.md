# Kernel 134 — lattice-guided pixel wash

Open `index.html` in Chromium. Switch between **FREE FLOW** and **LATTICE GUIDED** to compare the flow of one injected registry pixel per tick. The coupling slider adjusts angular steering toward the closest of 24 paths. Live telemetry summarizes /24, /12, /4, /3 and alignment error.

Preserved: 366-position registry (orange 1–122, green 123–245, teal 246–366), three 120° vectors, eight Josophene states, fading trails, gray wash and SVG export. Prior heads remain untouched.

This is exploratory computational art, not experimentally validated physics.
