MANUAL ONE-WAY DELIVERY

1. Append a witness observation in Gate 08 using a registered GitHub account.

2. OFFER a temporal event to a destination repository.

3. For 0root, create a receiver ACK file in the Hallway repository. It verifies the OFFER against TOPH first.

4. Find the ACK file's public Git blob SHA in Gate 07; then use the TOPH delivery Action again with RECEIPT, OFFER number, path and SHA.

The TOPH workflow writes only to TOPH. The receiver workflow writes only to its own repository. The bridge is a two-step, proof-bearing exchange—not shared private filesystem access or unattended work.
